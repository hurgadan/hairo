# Hairo

AI-сервис примерки причёсок: пользователь загружает селфи → визард вопросов → подбор из каталога причёсок → генерация фото с выбранной причёской. Web-first, с обёрткой в Telegram Mini App.

**Язык общения в проекте: русский.**

## Кратко зафиксировано

- Качество модели валидировано вручную (Валерия, жена основателя).
- Платформа: **web-first**; Telegram Mini App = обёртка над тем же web-app. WhatsApp — только уведомления/ссылки.
- Канал: пан-европейская русскоязычная диаспора в Telegram (плацдарм) → коренной DACH. i18n RU/ES/DE.
- Биллинг: ИП (Einzelunternehmen, DE) + Stripe.
- Стек: **Node.js + NestJS** (backend), **Nuxt.js** (frontend). Модель генерации — Nano Banana / Gemini 2.5 Flash Image.

## Текущий статус

**Фаза 0 (продукт) — закрыта:** таксономия, каталог (30 образов), визард, фильтрация, флоу+монетизация, промпт-шаблоны.
**Фаза 0.5 (дизайн) — закрыта:** бренд, токены light/dark, дизайн-система, 8 экранов → `DESIGN.md` + `Hairo Design.dc.html`.
**Фаза 1 (технический фундамент) — закрыта:** NestJS/Nuxt-каркас, Postgres+TypeORM+миграции, DTO/`transformToDto`, `auth`/`users` (JWT + Telegram initData), docker-compose (dev + test), CI (lint/build/e2e), фронт на токенах `DESIGN.md` (каталог — на реальном API, остальное на моках), контракты `@hurgadan/hairo-contracts`.

**Фаза 2 (сквозной срез генерации) — закрыта:** `photos` + `generation` (улучшение + рестайлинг, реальный веб-экран ожидания/результата) + GDPR-база (согласие, публичная политика `/privacy`, автоудаление фото по сроку неактивности — `retention`-модуль).
**Фаза 3 (каталог + визард + фильтрация) — закрыта:** `catalog`, автодетект (`face-analysis`), визард с префилом из автодетекта, фильтрация/ранжирование каталога по ответам (бэкенд), single-select выбор → генерация по выбранному.

**Фаза 4 (биллинг и баланс) — закрыта, кроме Stripe:** `billing` (кредиты + леджер, атомарное списание), гейтинг генерации по балансу (402 + рефанд при сбое), экран пополнения и история транзакций на реальном API. Trial-кредит даётся только при заведении аккаунта (регистрация / первый Telegram-вход), гостевой сессии — нет. Срез Stripe отложен до заведения аккаунта в Stripe.

**Фаза 4.5 (аккаунты) — закрыта:** `mail`-модуль (SMTP/log-транспорты, Mailpit локально), passwordless-вход `POST /auth/otp/request` + `/auth/otp/verify` (6 цифр, TTL 10 мин, лимиты на адрес и IP), линковка гостевой учётки при регистрации (тот же `user.id`), модалка регистрации на кнопке «Сгенерировать» + состояние «залогинен» на вебе. Веб-флоу проходится до конца.

**Дальше — Фаза 5 (i18n + Telegram Mini App):** i18n идёт первым (не заблокирован ничем), Mini App — последним срезом, потому что требует публичного HTTPS-домена, то есть деплоя. Решения и срезы — в `ROADMAP.md`.

См. `ROADMAP.md` для полного чеклиста по фазам.
